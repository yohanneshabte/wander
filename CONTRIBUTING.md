# Contributing

1. Fork [wander](https://github.com/yohanneshabte/wander).
2. `npm install && npm run typecheck && npm run test`
3. One idea per PR. Occupancy rules live in `src/lib/spa/engine.ts` — change
   them there, not in the React calendar.
4. Do not add secrets. Do not add real partner names as "affiliated" without
   a written yes.
5. Comments: one line at the top of a module stating *why*. Searchable tokens
   (`75% cap`, `site partition`, `offline Search`) beat essays.

Fuzzy-search map: [README.md](README.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
